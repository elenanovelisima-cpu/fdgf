# Extensión autopubli24 - WhatsApp Web Auto-Sender

Extensión de navegador para automatizar el envío desatendido de WhatsApp Web para anunciantes de autopubli24.

## 🚀 Guía de Instalación en 3 Clics (Chrome / Edge / Brave)

1. Abre tu navegador (Google Chrome, Microsoft Edge o Brave).
2. Entra a la página de extensiones escribiendo en la barra de direcciones:
   ```text
   chrome://extensions/
   ```
   *(o `edge://extensions/` en Edge, o `brave://extensions/` en Brave)*
3. En la esquina superior derecha, activa el interruptor **"Modo de desarrollador"**.
4. Haz clic en el botón **"Cargar descomprimida"** (Load unpacked).
5. Selecciona esta carpeta (`chrome-extension`).

¡Listo! Verás el icono verde de **autopubli24** en tu barra de extensiones.

## 📲 Cómo Usarla

1. Ten una pestaña abierta con tu sesión de WhatsApp Web iniciada (`https://web.whatsapp.com`).
2. Haz clic en el icono de la extensión autopubli24.
3. Pulsa **"Sincronizar"** para cargar automáticamente los anuncios pendientes desde tu panel web.
4. Elige el tiempo entre envíos (por ejemplo, 90 seg con ±15s aleatorio).
5. Pulsa **"Iniciar Automático"**.
6. La extensión abrirá cada chat, esperará a que cargue, pulsará Enter por ti, esperará la pausa de seguridad y pasará al siguiente contacto, marcándolo en tu panel como contactado.
